# Master Rules for Premium Web Development System

1. **Component-First**: The system is built entirely of reusable components. Pages compose components. Never build static HTML pages or duplicate UI logic.
2. **Quality First**: Visual excellence and performance are equally prioritized. Do not compromise on accessibility or responsive design.
3. **No Unnecessary Dependencies**: Justify every new package. Prefer native CSS/React solutions or high-quality existing tools.
4. **Design Tokens**: All layout, spacing, and styling should be derived from central design tokens in Tailwind and global styles.
5. **Progressive Enhancement**: Start with strong foundations (accessibility, responsive) and enhance with animations and 3D gracefully.
