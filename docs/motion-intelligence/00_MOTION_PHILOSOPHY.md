# Motion Philosophy

Motion must never be added merely because a page "looks empty" or because "glassmorphism looks cool". Every animation must have a purpose.

## AI Motion Decision Framework
Before adding animation, ask:
1. Does motion communicate hierarchy?
2. Does it provide feedback?
3. Does it improve spatial understanding?
4. Does it establish continuity?
5. Does it guide attention?
6. Does it make an interaction feel responsive?
7. Does it reinforce the brand personality?

If the answer is NO to all of these: DO NOT ADD MOTION.
