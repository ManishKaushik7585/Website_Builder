# Technology Stack

This project is built using:

- **Framework**: Next.js (16.3.2) - App Router
- **UI Library**: React (19.2.8) & React DOM (19.2.8)
- **Language**: TypeScript (5.9.3)
- **Styling**: Tailwind CSS (4.3.3)
- **Linting & Rules**: ESLint (9.39.5) & eslint-config-next (16.3.2)

*Environment:*
- **Node.js**: v26.7.0
- **npm**: 11.19.0

*Future Readiness*: The stack is prepared to support Framer Motion / GSAP for animations, and Three.js / React Three Fiber for 3D elements, but these are NOT installed until explicitly required.
