# AI AGENT RUNTIME RULES

## Principle
The runtime treats the AI provider as an untrusted operator that must be bound by strict structural constraints.

Canonical process:
RECEIVE BRIEF → INTERPRET → ASSEMBLE CONTEXT → SELECT CAPABILITY → REQUEST STRUCTURED OUTPUT → VALIDATE → EXECUTE THROUGH ENGINE → INSPECT → DIAGNOSE → REFINE → RENDER AGAIN → COMPARE → CONVERGE → ACCEPT / REJECT
