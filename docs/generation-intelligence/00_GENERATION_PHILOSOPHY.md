# GENERATION PHILOSOPHY
AI generation is a reasoning problem rather than a JSX-generation problem.
The system should prioritize:
1. Intent
2. Information architecture
3. Content
4. Visual hierarchy
5. Art direction
6. Assets
7. Motion
8. Composition
9. Implementation
10. QA

The AI should never begin with: "What components should I create?"
It should begin with: "What does this website need to accomplish?"
