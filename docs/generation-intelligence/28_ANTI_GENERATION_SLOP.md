# ANTI-GENERATION SLOP
Explicitly prohibit:
- generic SaaS layouts
- excessive cards
- meaningless gradients
- purple AI blobs
- fake statistics
- generic testimonials
- fake logos
- meaningless motion
- excessive rounded containers
- redundant headings
- excessive CTAs
- decorative UI without purpose
- random asymmetry
- arbitrary component creation
- invented technical claims

The generator should prefer: specificity + restraint + semantic hierarchy + structural variation + purposeful composition over visual novelty.
