# REGRESSION POLICY

## Principle
AI should make decisions at the highest appropriate abstraction level before implementation begins.
No lower layer may override the intent of a higher layer without explicit justification.

## System Hierarchy
BRIEF → RESEARCH → PAGE OBJECTIVE → CONTENT INTELLIGENCE → VISUAL INTELLIGENCE → ART DIRECTION → ASSET INTELLIGENCE → MOTION INTELLIGENCE → PAGE CONFIGURATION → PAGE TEMPLATE → SECTIONS → PATTERNS → COMPOSITES → PRIMITIVES → TOKENS → RENDERED PAGE → QA
